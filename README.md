# Representación de Código Intermedio

Programa que permite la representación del código intermedio de expresiones matemáticas.

## Características

- Conversión de notación infija a postfija (Notación Polaca)
- Generación de Triplos
- Generación de Cuádruplos
- Evaluación de expresiones numéricas
- Soporte para variables (letras)
- Soporte para operadores: +, -, *, /, ^, ( )

## Tecnologías

- React 19
- Vite 6
- Tailwind CSS 4.1

## Instalación

```bash
pnpm install
```

## Ejecución

```bash
pnpm dev
```

## Uso

1. Ingresa una expresión matemática en notación infija
2. Haz clic en "Procesar"
3. Visualiza los resultados en:
   - Notación Polaca (Postfija)
   - Tabla de Triplos
   - Tabla de Cuádruplos

## Ejemplos de expresiones

- `3 + 5 * 2`
- `(5 + 3) * (2 - 1)`
- `a + b * c`
- `(x + y) / z`
